and on-chain automation. Published from @CUNGYIOOOO on 25 November 2026:

> #AI #Crypto #AIAgents #Web3 makefun-tent-cloud-burrow

Live post: https://x.com/CUNGYIOOOO/status/2125565342395081096

## How it works

`main.py` writes `/output/POST.json` containing the URL of the published
X post:

```json
{"url": "https://x.com/CUNGYIOOOO/status/2125565342395081096"}
```

Run it with:

```bash
python3 main.py
```
